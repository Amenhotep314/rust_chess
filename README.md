- [Chess Coding Adventure](https://www.youtube.com/playlist?list=PLFt_AvWsXl0cvHyu32ajwh2qU1i6hl77c)

GUI programming (equi, WGPU), and raytracing, but I think those will be more
rewarding after doing this.
